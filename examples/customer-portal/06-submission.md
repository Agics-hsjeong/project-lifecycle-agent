# 제출 점검 예시

현재 상태: 설명용 초안. 실제 제출·승인·리허설·렌더링 완료 기록 없음.

| 항목 | 상태 | 다음 작업 |
| --- | --- | --- |
| RFP 목차·평가기준 | 초안 대응 | 원문과 최종 내용 대조 |
| 제안 편집본·PDF | 미제작 | 호스트 제작 도구로 생성·전체 렌더링 |
| 산정서 | 가정 초안 | 실제 인력·단가·범위 확정 |
| 발표자료·대본·Q&A | 텍스트 구성 | PPTX 제작, 장수·시간·렌더링·리허설 확인 |
| 평가 대응·증빙 | 초안 연결 | 실제 근거와 파일 경로 확인 |
| 이전 고객 정보 잔존 | 미검수 | 작업 사본의 내용·노트·주석·메타데이터 검수 |
| 버전·파일 목록 | 미확정 | 최종 파일의 버전·경로 확정 |
| 제출 기한·대상·권한 | 미확정 | 실제 담당자 결정과 원문 조건 확인 |

초안 파일이 있다는 이유로 최종 제출본을 완료 처리하지 않는다. 모든 제작·검수와 사업 결정은 실제 작업에서 기록한다.
