# 인수인계 예시 - 가상 사례

## 현재 상태

RFP와 요구사항·질문·제안 텍스트 초안을 정리한 상태를 설명하는 예시다. 이 문서는 실제 고객 프로젝트의 HANDOFF.md나 엔진 상태 파일을 대신하지 않는다.

## 작성한 자료

RFP.md, 요구사항표, 제안서 본문, 가정 산정, 평가 대응표, 10분 발표 구성·대본·Q&A와 제출 점검 예시.

## 미실행·미결정

실제 프로젝트 생성·검토 승인, 고객 답변, 참고 DOCX/PPTX의 스타일 분석, 편집본 제작·렌더링·비교 검수, 실제 테스트·배포·제출은 이 정적 예제에서 수행하지 않았다.

## 다음 행동

사용자의 업무 폴더에서 project-lifecycle 스킬로 RFP 원본을 등록한다. 엔진이 배정한 ID와 실제 기록을 사용한다. 예산·인력·인증·알림·첨부·호스팅을 확인한 뒤 산정을 조정한다. 자기 템플릿을 등록하고 실제 제작·검수를 요청한다.
