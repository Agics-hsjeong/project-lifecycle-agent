# 범위·공수·일정 산정 예시 - 가상 가정

이 표는 산정 방식 설명용이며 견적이나 실제 팀의 생산성·인력 약속이 아니다. 1인일은 1인이 하루 일하는 작업량 단위이며 기간과 동일하지 않다.

| 작업 묶음 | 가정 공수 | 근거 |
| --- | --- | --- |
| 요구사항·정책·설계 | 8인일 | 역할·문의 흐름·화면·데이터 기준 정리 |
| UI·퍼블리싱 | 7인일 | 핵심 고객·운영 화면과 반응형 |
| 계정·권한·문의·운영 구현 | 16인일 | REQ-001~004의 주요 경로 |
| 통합·권한·접근성·회귀 검증 | 6인일 | REQ-001~005 수용 기준 |
| 배포 준비·매뉴얼·인수 | 3인일 | REQ-006 |
| 합계 | 40인일 | 실제 인력·환경 답변 후 재산정 |

6주 동안 일부 작업의 병행을 가정한다. 역할별 실제 투입률과 담당자는 미정이다. 단가·예산·세금·운영비·예비비가 확정되지 않아 금액을 산출하지 않는다.

## 6주 일정 가정

1주 차 정책·범위·설계 / 2~4주 차 UI와 핵심 경로 구현 / 5주 차 통합·회귀 검증 / 6주 차 고객 확인·배포 준비·인수.

첨부파일·알림·SSO 연동·추가 운영 요건은 고객 답변 후 변경 영향을 분석한다.
