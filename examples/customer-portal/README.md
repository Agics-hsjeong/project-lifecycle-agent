# 고객 포털 가상 예제

이 자료의 고객·일정·요구사항·평가기준은 사용법을 설명하기 위해 만든 **가상 사례**입니다. 실제 고객 자료를 포함하지 않습니다.

## 들어 있는 것

- RFP.md: 입력할 제안요청서
- 01-requirements.md: 원문 근거와 수용 기준을 연결한 결과 예시
- 02-proposal.md: 정성제안서의 짧은 본문 예시
- 03-estimate.md: 범위·공수·일정 가정과 산정 예시
- 04-evaluation.md: 평가항목과 제안서·발표의 대응
- 05-presentation.md: 10분 발표 5장 구성·대본과 예상 Q&A
- 06-submission.md: 실제 제작·제출 전 점검 항목
- 07-handoff.md: 현재 상태와 다음 작업을 기록하는 예시

## 사용하기

1. Codex 또는 Claude Code에서 자기 업무용 폴더를 엽니다.
2. 프로젝트이음의 project-lifecycle 스킬을 불러옵니다.
3. RFP.md 경로를 전달하고 새 외주 사업을 시작해 달라고 요청합니다.
4. 아래 결과 파일은 비교·학습 자료로 읽습니다. 실제 프로젝트 원장에 그대로 승인·완료 기록으로 복사하지 않습니다.
5. 자기 DOCX·PPTX 참고 자료가 있다면 생성된 templates 폴더에 넣고 스타일 분석과 실제 파일 제작을 요청합니다.

이 예제의 결과는 텍스트로 작성한 설명용 기준안입니다. 실제 엔진 실행 결과나 고객 승인 증거, 최종 DOCX·PPTX·PDF 제출본으로 표시하지 않습니다. 숫자·작업량·납기는 이 가상 사례의 가정입니다.

## 시작 요청문

```text
Project Lifecycle Agent로 이 가상 RFP의 고객 포털 사업을 시작해줘.
현재 업무 폴더에 프로젝트를 만들고 식별자는 portal-demo로 해줘.
원본·요구사항·평가기준·고객 질문과 제안 초안을 작성해줘.
가상 예제임을 표시하고 고객 승인·실적·테스트 결과는 만들어내지 마.
```
