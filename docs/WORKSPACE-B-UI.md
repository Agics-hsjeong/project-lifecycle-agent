# B안 관제 UI · 적용 및 점검 기록

2026-11-19. 선택한 B 시안의 밝은 작업 영역과 짙은 사이드바를 실제 React 관제 화면에 적용했다. 미배포 개발 작업본이며 실제 프로젝트 데이터와 로그를 읽는다. 공개 시뮬레이션은 별도 모드로 표시한다.

## 적용한 구조

왼쪽 탐색에는 현재 프로젝트, 실행 현황, 워크플로우, 작업 지도, 타임라인, 산출물과 실제 보고된 호스트를 배치했다. 연결된 실행기와 실제 활성 작업자를 구분한다. 동작 없는 설정이나 가짜 프로젝트 전환 버튼은 만들지 않는다.

실행 현황은 상태별 작업 표다. 전체/진행/대기/완료 탭, 검색과 역할·업무 단계 필터를 제공한다. 전체 진척은 snapshot 전체 작업 기준이며 필터나 검색으로 바뀌지 않는다. 이전 카드 보드와 중복된 다섯 단계 상단 카드는 제거했다.

데스크톱에서 작업을 선택하면 오른쪽에 실제 역할·호스트·파일·현재 행동·경과 시간과 최근 활동을 표시한다. “전체 활동”으로 프로젝트 타임라인을 보고 “작업 상세 보기”로 전체 기록·의존성·파일 Diff를 연다. 파일 열기는 원장에 연결된 실제 산출물을 조회한다. 승인 입력과 임의 실행 명령은 추가하지 않았다.

표 아래 역할별 작업 흐름은 실제 실행 시도와 활동 시각을 표시한다. 첫 시도와 재시도를 구분하고, 최신 시도의 시작·종료를 우선한다. 계획 일정을 실제 실행처럼 사용하지 않는다. 실행 시각이나 호스트가 없는 작업은 미보고로 표시한다. 완료·실패·오래된 running 기록을 현재까지 늘리지 않는다. 별도 타임라인 메뉴는 예정 일정과 실제 실행 기록의 WBS다.

## 모바일

왼쪽 탐색은 메뉴 버튼으로 열며 내부 닫기 버튼과 Escape, 키보드 포커스 이동을 제공한다. 작업을 누르면 전체 화면 상세가 열리고, 닫으면 선택한 항목으로 포커스가 돌아온다. 표는 작업·담당·상태를 세로로 재배치하고 시간표만 자체 가로 스크롤을 사용한다.

검색 입력과 선택 컨트롤은 모바일 16px로 확대 자동 동작을 줄이고, 주요 버튼은 44px 터치 영역을 확보했다. 데모 일시 정지와 읽기 전용 스냅샷 열기는 모바일 메뉴에서도 사용할 수 있다. 상태 숫자는 한 줄, 진행 막대와 상태는 그 아래에 배치한다.

## 실제 데이터와 검증

실제 loopback 서버의 inquiry-trial을 읽었다. 기존 작업 3개 완료와 전체 100%, 백엔드 최신 실행 62초, QA 95초, 아키텍트의 실행 시각·호스트 미보고를 확인했다. 기존 사용자 결정·산출물·실행 기록은 변경하지 않았다.

- TypeScript 및 Astro 20페이지 빌드 통과.
- 상태/호스트/시간 계산 독립 점검 12개와 역할 타임라인 계산 사례 8개 통과.
- 실제 화면의 검색·필터·선택·메뉴·상세·5개 탐색 뷰 등 74개 검사가 통과했다.
- 분리한 브라우저 route fixture의 20개 검사가 통과했다. 새 활동의 자동 수신, 오래된 실행, 연결 끊김/복구, 읽기 전용 스냅샷·미보고 시각, 모바일 데모 재생·일시 정지와 파일 선택을 확인했다. 이 fixture는 실제 모델 실행 결과로 계산하지 않는다.
- Edge headless의 320/390/768/1440px와 상세·그래프·WBS·산출물 화면을 검사했다. 11개 axe WCAG 2A/AA·2.1A/AA 검사에서 위반 0건, 페이지 가로 넘침 0건을 확인했다. 실기기 Safari/Android 검증이나 접근성 인증은 아니다.
- 초기 접근성 검사에서 버튼 이름과 보이는 글자 불일치, 메타데이터 대비, 이전 모바일 레이아웃과의 충돌을 수정했다. 최종 JS 오류·HTTP 실패·조회 중 POST 요청은 모두 0건이다.

로컬 근거는 `.test-output/b-ui/qa-b-browser.json`, `qa-edge-fixtures.json`, `qa-final-1440.png`, `qa-final-390.png`, `qa-final-inspector-390.png`에 보존한다. 실제 시간 계산 helper 점검은 `.test-output/b-timeline-check.mjs`와 독립 QA 기록을 사용한다. 고객 자료·접속 토큰·미리보기 사본은 배포하지 않는다.

## 2026-11-20 · 세 관제 뷰 정리

워크플로우·작업 지도·타임라인은 흰색 프레임, 밝은 회색 캔버스, 공통 검색/필터 도구막대와 하단 범례를 사용한다. 메인 레이아웃과 실제 프로젝트 연결은 유지한다.

- 워크플로우: 동일 규격의 작업 카드, 절제된 상태 표시, 카드 바깥의 수정 연결선과 밝은 미니맵.
- 작업 지도: 요구사항·작업·산출물·실행자를 종류별로 정렬하고 실제 연결만 표시한다. 같은 관계의 표기 별칭은 중복 제거하며 선택한 항목의 연결을 강조한다. 주기적인 활동 수신과 상태 갱신은 사용자의 이동·배율을 유지한다. 3D 탐색도 밝은 캔버스를 사용한다.
- 타임라인: 접을 수 있는 단계와 고정 작업 열, 실제 달력 기준 일·주·월 축. 연한 회색 막대는 예정 일정, 청록 표식은 실제 실행 기록이다. 실행 시각이 없는 작업에 가상 막대를 만들지 않는다. 현재 날짜는 표시 범위 안에 있을 때만 나타난다.

모바일에서는 읽기 쉬운 작업 목록을 먼저 보여주고 ‘캔버스 보기’로 전환한다. 상세·필터·줌·기간 전환은 프로젝트 기록을 수정하지 않는다.

검증: 실제 로컬 프로젝트의 3개 완료 작업, 16개 지도 항목과 21개 실제 관계를 확인했다. 데스크톱 1440/1600px 및 모바일 320/390/768px에서 화면 전환·선택·검색·필터·줌·단계 접기·일/주/월 전환 등 브라우저 검사 82개, 독립 의미/갱신 검사 37개가 통과했다. 검색/필터 추가 검사 20개 및 3D·실행자 식별 집중 검사 14개까지 총 153개를 확인했다. 총 27개 axe WCAG 2A/AA·2.1A/AA 검사에서 위반·페이지 가로 넘침 0건이며 JS 오류·HTTP 실패·조회 중 POST도 0건이었다. 갱신 검사는 별도 브라우저 응답 fixture를 사용했고 고객 원장을 수정하지 않았다. 미니맵 SVG 잘림, 지도 초기 배치와 보조 글자 대비를 검사 과정에서 수정했다.

달력 계산은 KST 경계·월요일 주 시작·28/29/31일 월·연말·미등록/역전 일정·과거 일정·눈금 수 제한 등 11개 사례를 확인했다. TypeScript, Astro 20페이지/1,039개 로컬 링크, 자산 무결성 5개 및 패키지/추출 실행 5개 검사도 통과했다. 실기기 iOS/Android 검증이나 접근성 인증은 아니다. 근거는 로컬 `.test-output/scenes-ui/qa-scenes-browser.json`, `qa-scenes-deep.json`에 보존한다.

3D는 화면 크기에 맞춘 초기 배율과 전체 맞춤을 적용했고, 작업/선택/호버 중심으로 라벨을 정리했다. 모바일은 기본 작업 목록과 2D 관계 탐색을 제공하며 3D에서도 실제 항목을 선택해 상세를 확인할 수 있다. 추가 근거는 `qa-filters.json`, `qa-final-3d.json`에 보존한다.
