에이전트가 완료한 파일과 검수 근거의 경로를 안내합니다. 아래 폴더는 프로젝트별로 관리하며 제작 시 필요한 폴더가 추가됩니다.

| 위치 | 보관 내용 |
| --- | --- |
| project.json | 사업 유형·방법론·현재 단계·기술 정보 |
| AGENTS.md / CLAUDE.md / process/ | 프로젝트 지침·업무 규칙 |
| HANDOFF.md | 변경·검증·미결정·다음 작업 |
| inputs/ | RFP·고객 답변의 원본·출처·버전 |
| templates/ | 참고 원본·대표 선택·스타일 분석·비교 검수 |
| docs/ | 단계별 업무 문서 |
| registers/ | 요구사항·작업·산출물·리스크 등 원장 |
| working/templates/ | 제작 시 만드는 편집 작업 사본 |
| exports/ | 제작 시 만드는 최종 결과 파일 |
| state/ | 내부 변경·복구 기록. 직접 수정하지 않음 |

## 자료와 결과의 관계

RFP 원문 → 요구사항·평가항목 → 제안서 절·슬라이드·증빙 → 설계·코드 → 테스트 → 납품·운영 기록을 연결합니다. 단순히 폴더가 존재한다고 내용이나 완료가 검증된 것은 아닙니다.

## 자료 보존 원칙

- 플러그인 코드와 고객 프로젝트 위치를 분리합니다.
- 다른 고객의 원본·실적·가격을 새 사업의 사실로 복사하지 않습니다.
- 기존 프로젝트를 새 기본형으로 통째로 덮어쓰지 않습니다.
- 업데이트 시 차이·범위·이행 방법을 기록하고 필요한 항목을 보존하며 추가합니다.
- 공개 저장소에서는 고객 원본·참고 자료의 제외 설정을 확인합니다.

## 현재 상태를 알려 달라고 요청하기

```text
현재 단계와 완료된 산출물의 실제 파일 경로를 알려줘.
미완료 작업, 검증 결과, 리스크와 다음 사업 결정을 정리해줘.
```
