# 프로젝트이음 웹 디자인 기준

갱신: 2026-11-03. GitHub Pages의 기존 주소·브랜드·공개 범위를 유지한다.

## 방향과 정보 구조

설치 안내에 더해 동작 구조와 목표 시스템을 시각적으로 설명한다. 제품 개요와 입체 연결도 → 실행 아키텍처 → 프로젝트 유형별 흐름 → 가상 고객 포털 목표 시스템 → 팀 템플릿 → 제품별 설치 → 문서·예제·FAQ 순서다.

- 따뜻한 흰 바탕·차콜 본문·청록 브랜드를 기본으로, 깊은 녹색의 기술 도면과 옅은 세이지의 목표 시스템 도면을 대비시킨다. 격자와 선은 정보의 연결과 계층을 표현한다.
- 큰 한글 제목·정렬·여백·얇은 구분선을 사용한다. 입체 이미지는 입력·관리·산출물의 관계를 표현한다. 가상 진행률·고객 후기·이용 수치는 넣지 않는다.
- 첫 화면의 연결 그림은 개념 시각화다. 아키텍처는 실제 스킬·Python 엔진·프로젝트 파일의 관계를 표현한다. 작업 수행 주체는 활성 호스트이며 별도 상시 서버나 두 제품 간 자동 대화 동기화로 설명하지 않는다.
- 목표 시스템은 공개 가상 RFP의 2.1–2.6을 해석한 기술 제품 중립 개념 설계다. 실제 구축 화면으로 제시하지 않는다. 인증 방식·기술 제품·호스팅은 미확정이다. 비로그인 FAQ·공지와 개인 문의의 권한 경계를 구분한다.
- 접근 제어·데이터 흐름 버튼은 해당 구성요소를 강조하고 설명을 갱신한다. aria-pressed와 라이브 설명을 사용하며 키보드로 조작할 수 있다.
- SI 11·제품 6·API 9·유지보수 6단계 선택은 실제 엔진 프로필과 맞춘다.
- Codex의 설치 요청문과 Claude Code의 설치 명령을 구분한다. 복사 실패 시 내용을 선택해 직접 복사할 수 있게 한다.
- 모바일·태블릿에서는 글자를 작게 축소하는 대신 별도 세로형 도식을 사용한다. 구조도 원본 SVG도 새 탭으로 제공한다.

## 서체와 시각 자산

Pretendard 가변 서체를 자체 호스팅한다. 원본: https://github.com/orioncactus/pretendard. SIL Open Font License 1.1 전문과 저작권 고지는 public/fonts/OFL.txt에 함께 배포한다. 기존 프로젝트이음 로고를 유지한다.

세 종류·두 화면 구성의 SVG 6개는 이 저장소에서 직접 작성한 원본이다. 확대해도 선명하고 각각 7 KB 미만이다. 외부 이미지·모델 생성 비트맵·새 런타임 의존성을 추가하지 않는다. 생성 소스와 수정 방법은 [도식 안내](public/diagrams/README.md)를 참고한다. 목표 시스템은 HTML에 SVG를 포함해 강조 상태를 연결하고, 첫 화면 이미지에는 화면별 picture 소스를 사용한다.

## 검증 범위

- Astro 프로덕션 빌드·사이트 버전 검사·HTML 16페이지의 로컬 링크와 자산 검사.
- 격리된 Windows Edge/Playwright에서 1440·1024·768·640·390·320px 화면과 SVG 텍스트 영역 검사. 데스크톱·모바일 도식을 캡처해 시각 검수.
- 전체·접근 제어·데이터 흐름 전환, Enter 조작, 선택 상태·강조 테두리·설명 갱신, 화면별 도식 선택, 중복 ID 없음, reduced-motion 설정 확인.
- 네 프로젝트 유형·키보드 방향키·두 제품의 클립보드 복사·복사 실패 대안·FAQ·모바일 메뉴·문서 탐색·Ctrl+K 한국어 검색 확인.
- 홈 데스크톱/모바일·문서 밝은 데스크톱/어두운 모바일에서 axe-core WCAG 2 A/AA·2.1 A/AA 자동 검사. SVG 겹침 때문에 자동 판단을 보류한 색 대비는 명시한 전경·배경 조합으로 계산하고 시각 검수한다. 모든 장애 환경에 대한 인증이나 전수 적합성 보증을 뜻하지 않는다.
- 브라우저 오류·실패한 HTTP 리소스 확인.

웹 UI·시각 자료만 변경하며 플러그인 실행 코드·고객 프로젝트·기존 릴리스 태그는 변경하지 않는다. 실행 기록과 캡처는 로컬 .test-output/site-design에 보관한다.
