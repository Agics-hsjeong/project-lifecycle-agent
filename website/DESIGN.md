# 프로젝트이음 웹 디자인 기준

갱신: 2026-11-03. GitHub Pages의 기존 주소·브랜드·공개 범위를 유지한다.

## 방향과 정보 구조

큰 홍보 문구와 가상 채팅·기울어진 문서 장식 중심의 구성을 정리했다. 제품의 용도 → 실제 예제의 연결 구조 → 프로젝트 유형 선택 → 팀 템플릿 활용 → 제품별 설치 → 문서·예제·FAQ 순서로 구성한다.

- 흰 바탕·차콜 본문·브랜드 청록을 사용한다. 청록은 주로 동작과 현재 선택 상태를 표시한다.
- 문서 같은 정렬·얇은 구분선·일관된 글자 위계로 내용을 구분한다. 불필요한 그라디언트·카드 회전·가상 진행률·고객 후기·이용 수치 장식을 넣지 않는다.
- 공개 고객 포털 가상 예제의 REQ-001을 사용한다. 연결 구조 설명임을 표시하고 실제 고객 승인·실행 화면처럼 제시하지 않는다.
- SI 11·제품 6·API 9·유지보수 6단계 선택은 실제 엔진 프로필과 맞춘다.
- Codex의 설치 요청문과 Claude Code의 설치 명령을 구분하고 입력 위치를 명확히 안내한다. 복사 실패 시 내용을 선택해 직접 복사할 수 있게 한다.
- 모바일에서도 같은 순서로 읽힌다. 위치를 가정하는 “오른쪽” 등의 지시문은 피한다.

## 서체와 자산

Pretendard 가변 서체를 자체 호스팅한다. 원본: https://github.com/orioncactus/pretendard. SIL Open Font License 1.1 전문과 저작권 고지는 public/fonts/OFL.txt에 함께 배포한다. 기존 프로젝트이음 로고를 유지한다. 외부 Google Fonts 요청은 제거했다.

## 검증 범위

- Astro 프로덕션 빌드, HTML 16페이지·670개 로컬 링크/자산 검사 통과.
- 격리된 Windows Edge/Playwright에서 1440·1024·768·390·320px 가로 넘침 없음. 데스크톱·모바일 전체 화면을 캡처해 시각 검수.
- 네 프로젝트 유형 선택·키보드 방향키·두 제품의 클립보드 복사·복사 권한 실패 대안·FAQ·모바일 메뉴 열기/닫기/Escape·문서 탐색 통과.
- 문서 검색의 Ctrl+K와 “템플릿” 한국어 검색 결과 확인. 검색 버튼의 중복 시각 단축키 힌트를 정리하되 실제 단축키와 aria-keyshortcuts는 유지.
- axe-core의 WCAG 2 A/AA·2.1 A/AA 검사에서 홈 데스크톱/모바일·문서 밝은 데스크톱/어두운 모바일의 자동 검출 위반 0건. 장식 화살표의 색 대비 자동 판독 보류는 직접 확인했다. 모든 장애 환경에 대한 인증이나 전수 적합성 보증을 뜻하지 않는다.
- 브라우저 콘솔 오류·실패한 HTTP 리소스 없음.

이번 변경은 웹 UI에 한정하며 플러그인 실행 코드·고객 프로젝트·기존 릴리스 태그는 변경하지 않는다. 검증 이미지·실행 기록은 로컬 .test-output/site-design에 보관한다.
