# 프로젝트이음 / Project Ieum

사용자가 선택한 브랜드와 로고를 보관합니다.

- `logo-lockup.png`: 심볼 + 프로젝트이음 + Project Ieum 가로 조합
- `symbol.png`: 연결된 두 고리의 심볼 단독
- 색상 기준: 청록 `#087F8C`, 딥네이비 `#142A42`
- 의미: 제안·개발·운영의 단계와 사람·AI의 작업 연결
- 형식: 투명 배경 RGBA PNG. 벡터 원본으로 표시하지 않음
- 제작: 대화에서 이미지 생성 도구로 제작하고 사용자가 선택한 원본

생성 기준: 두 둥근 사각 고리가 중앙의 연결부로 이어지는 간결한 형태, 한글·영문 이름, 청록·네이비 색상, 작은 크기에서도 읽히는 실루엣과 투명 배경.

홈페이지의 표시는 CSS로 크기를 조정합니다. 원본 PNG는 변경하지 않습니다.
