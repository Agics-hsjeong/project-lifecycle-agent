# 이음

이 파일은 프로젝트별 `/ieum` 진입점이다. 작업 규칙을 별도로 복제하지 않는다.

1. 사용자의 아래 요청을 받는다. Skill 도구가 있으면 정확한 이름 `project-lifecycle-agent:ieum`으로 설치된 플러그인 스킬을 불러오고, 사용자 요청을 args로 그대로 전달한다. `ieum`이라는 짧은 이름을 다시 호출해 재귀하지 않는다.
2. 요청이 비어 있으면 같은 플러그인에 도움말을 요청한다.
3. 새 플러그인 스킬을 찾지 못하면 기존 `project-lifecycle-agent:project-lifecycle`을 확인하고 같은 요청을 전달한다. 모두 없으면 설치·활성화·실제 로딩 경로를 진단한다. 설치 캐시 경로를 추측하거나 엔진을 복제·우회하지 않는다.
4. 요청문을 셸 명령으로 실행하지 않는다. 작업·파일·외부 서비스 권한은 사용자 요청과 기존 호스트 설정을 따른다.
